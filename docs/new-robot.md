# 新机器人控制器接入

新型号创建独立仓库，例如 `ur_control`、`duco_control`。本仓库不添加厂商 SDK 分支。
首先实现 [接口 v1](interface-v1.md)，然后用这里的通用工具验收。

## 推荐开发顺序

1. 建立型号仓库：驱动/仿真后端、模型与工具标定、执行控制器、ROS 桥和 HTTP 服务分层。
   ROS namespace、网络地址、设备标识通过配置传入，启动默认不运动。
2. 只读获取真实反馈、设备版本及错误，建立关节名、方向、单位、限位、TCP 偏移的准确映射。
   通过 `info` 报告自由度和能力；不要假定所有机器人都是六轴。
3. 实现显式 enable / stop / disable、反馈就绪和故障状态。独立控制循环及单调时钟看门狗
   放在型号控制器内；工具退出、ROS 断流都不能导致目标无限推进。
4. 实现 `servo_twist`：校验有限速度和 frame，基座/TCP 语义正确，使用厂家 Cartesian servo
   或该型号自己的 Jacobian/IK，加入关节限制、奇异点、加速度及厂商运行模式约束。
   此时可使用 SpaceMouse 做仿真输入，不需要改遥操代码。
5. 完成关节/TCP 实时目标和时间轨迹；不能支持的能力不宣称支持，请求明确返回错误。
   实现执行反馈、取消、中止及实际到位判据。只实现 twist 的控制器可做初期遥操，
   不能据此宣称完整通过 v1。
6. 在模拟器上先通过接口和行为测试，再按型号仓库的现场流程验收真机。
   将仓库地址、命名空间、能力、版本和验证结果添加到 controllers.yaml 及验证记录。

可参考现有 `nero_control/{controller,ros_bridge,server}.py` 和 Piper 对应文件的分层，
但不要复制 CAN 配置、电机增益、固件假设或未核实的标定。模型、SDK 的复用遵循各自许可证。

## 建议仓库骨架

```text
new_robot_control/
  model.py                 关节元数据、工具变换、限位
  controller.py            通用命令语义与型号执行约束
  backends/simulation.py   可重复的离线反馈和运动
  backends/hardware.py     厂商通信、状态、驱动错误
  ros_bridge.py            标准消息、服务、action
  server.py                API v1 与 OpenAPI
  __main__.py              --backend / --ros / --ros-namespace
tests/                     非法输入、断流、反馈故障、轨迹终态
docs/                      固件版本、标定、模式限制及验收证据
```

## 验收矩阵

| 场景 | 必须看到的行为 |
| --- | --- |
| 先启动控制器，后启动工具 | 无输入时不运动；话题匹配后接通，无需重启控制器 |
| 客户端只读连接/关闭 | 无 enable / stop / disable 副作用 |
| 六轴、七轴或其他数量 | 从 info/state 读取名字，维度和顺序正确 |
| 名字打乱、缺失、重复 | 可明确重排完整集合；不完整或重复明确拒绝 |
| NaN / Inf / 维度错误 / 不支持 frame | 拒绝执行并报告错误 |
| 实时流中断、工具崩溃 | 在配置超时内停止推进目标 |
| 反馈超时、驱动错误 | 中止任务，阻止继续运动，无伪造成功 |
| 停止/取消/失能 | 三种语义与接口文档一致 |
| 不可达轨迹、过短时长 | 执行前拒绝；不静默更改外部时序 |
| 轨迹完成 | 基于实测误差、速度和持续稳定时间 |
| 两个 namespace | 输入只作用于所选机器人 |
| 物理输入拔插、服务重启、网络中断 | 保存实测停止及恢复行为，核实输入缓存问题 |

第一轮运行 `robot_check --url URL --output report.json`，其后对新模拟器复用
`tests/test_controllers.py` 的真实 ROS 链路测试模式。报告中写明固件、模型、TCP、软件 commit、
限速和测试环境。静态快照检查、仿真通过、真机通过分别记录，不互相代替。

Piper 当前 CLI 没有 `--ros-namespace`，多个 Piper 接入时先在它自己的仓库新增该选项，
传给已经支持 namespace 的 RosBridge；不要在本工具里改全局话题字符串或硬编码第二台设备。
